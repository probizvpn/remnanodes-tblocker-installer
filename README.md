# Xray Torrent Blocker (tBlocker) Auto-Installer для Remnawave Node

>Запускать на Remnawave Node:

## Вариант 1:
### Сразу указать свой домен бота, на котором вебхуки для tBlocker, вместо mybotdomain.com - прописать свой домен:
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/probizvpn/remnanodes-tblocker-installer/refs/heads/main/tblocker_install.sh) -d mybotdomain.com
```

или 

## Вариант2:
### Без указания домена, в таком случае, скрипт сам запросит указать домен бота, на котором вебхуки для tBlocker:
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/probizvpn/remnanodes-tblocker-installer/refs/heads/main/tblocker_install.sh)
```
